## 👨‍💻 About Me

I am a **Software Engineer** and **MS Computer Science student at North Carolina State University**, interested in building systems that connect real-world application logic with scalable backend infrastructure, AI/ML models, and reliable deployment workflows.

My work spans **full-stack development, backend APIs, AI/ML applications, DevOps automation, distributed systems, and robotics/perception pipelines**. I enjoy working across the stack: from designing user-facing applications in **React**, to building APIs in **FastAPI / ASP.NET Core**, to containerizing services with **Docker**, automating CI/CD with **GitHub Actions**, and experimenting with **LLMs, computer vision, ROS 2, gRPC, and ONNX-based inference systems**.

- 🎯 **Focus:** Full-stack engineering, applied AI systems, backend infrastructure, and cloud-native software

## 🚀 Featured Projects

### 🤖 [Scalable Off-Board AI Perception Engine](https://github.com/KunalJindalDev/Scalabale-Off-Board-AI-Perception-Engine)
**Robotics / Systems / AI Inference | C++, ROS 2, gRPC, ONNX, Linux**

- Built a distributed off-board perception pipeline where simulated ROS 2 robots stream sensor data to a centralized C++ inference backend.
- Designed a gRPC middleware layer and multi-threaded inference server for asynchronous, high-throughput processing of robot perception workloads.
- Integrated ONNX Runtime for model inference and focused on latency-aware control loops, memory-safe tensor handling, and real-time robotics constraints.

### 🧠 [MedRAX — Rule-Guided Medical Diagnosis Agent](https://github.com/KunalJindalDev/rule-guided-medical-agent)
**Applied AI / Agentic Systems | Python, LangGraph, Llama 3.1, RAG, Multimodal Tools**

- Built a hybrid **rule-guided + LLM** medical reasoning agent with baseline and rule-enhanced modes for more structured diagnostic workflows.
- Integrated multimodal medical tools including X-ray classifiers, segmentation models, and VLM-based reasoning components.
- Added structured reasoning traces to make model behavior more transparent, debuggable, and easier to evaluate.

### ☁️ [Distributed Media Microservice](https://github.com/KunalJindalDev/-Distributed_Media_Microservice)
**Backend / Distributed Systems | C#, .NET 8, Docker, Redis, SQL Server, Dapper**

### 🦷 [DentalAI — Real-Time Panoramic X-Ray Analysis](https://github.com/KunalJindalDev/Dental-ai-platform)
