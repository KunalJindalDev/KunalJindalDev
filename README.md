## 👨‍💻 About Me

I am an **AI/ML-focused Software Engineer** and **MS Computer Science student** at **North Carolina State University**, interested in building intelligent systems that connect machine learning with scalable backend infrastructure, distributed systems, data pipelines, and reliable deployment workflows.

Most recently, I worked as an **AI Engineer Intern** at **Yodlee**, where I worked on large-scale transaction intelligence, entity resolution, graph-derived signals, agentic research workflows, and internal knowledge systems. My broader experience spans **full-stack development, backend APIs, AI/ML applications, DevOps automation, distributed systems, and robotics/perception pipelines.**

I enjoy working across the stack: from experimenting with **LLMs, embeddings, RAG, computer vision, and ML pipelines**, to building APIs in **FastAPI / ASP.NET Core**, designing distributed services with **gRPC**, working with **Spark and Airflow**, containerizing services with **Docker**, and automating infrastructure and CI/CD workflows.**.

- 🧠 **Interests:** ML systems, trustworthy AI, agentic workflows, retrieval & representation learning, scalable inference, computer vision, and infrastructure reliability

### 🤖 [Scalable Off-Board AI Perception Engine](https://github.com/KunalJindalDev/Scalabale-Off-Board-AI-Perception-Engine)
**Robotics / Systems / AI Inference | C++, ROS 2, gRPC, ONNX, Linux**

- Contributed to a distributed off-board perception pipeline where simulated ROS 2 robots stream sensor data through a gRPC layer to a centralized C++ inference backend.
- Built the ROS 2 simulation and control layer for a multi-robot fleet, including synchronized RGB/depth sensor capture and reactive obstacle avoidance.
- Integrated depth cameras into TurtleBot3 simulations using Gazebo/XACRO and developed fleet-level diagnostics for latency, frame throughput, and detections.
- The complete system sustained three concurrent robots at ~4 FPS each with 198–262 ms end-to-end latency.
